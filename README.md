# کارهای من — اپلیکیشن ساده To-Do برای اندروید

## اجرا
1. فایل ZIP را از حالت فشرده خارج کنید.
2. پوشه `DoListAndroid` را در Android Studio باز کنید.
3. صبر کنید Gradle Sync تمام شود.
4. روی گوشی یا شبیه‌ساز، برنامه را Run کنید.

## امکانات
- افزودن کار
- علامت‌گذاری انجام‌شده
- فیلتر کارهای انجام‌شده و باقی‌مانده
- حذف کار
- ذخیره محلی اطلاعات روی گوشی با SharedPreferences

## فناوری
Kotlin، Jetpack Compose و Material 3.
